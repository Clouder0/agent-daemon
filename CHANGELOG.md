## [0.1.0] - 2026-08-20

### Added

- Core daemon: per-agent durable pull consumers over NATS JetStream (ADR-0006 underscore ids — id == subject tail == consumer name == filename), slot-driven pulls with bounded reconnect recovery, double-ack/term, in-progress keepalive (ADR-0001)
- Dispatcher: one event → one handler invocation; original bytes on stdin; concurrency gates; atomic in-flight + completed dedup keyed `(agent_id, event_id)` (ADR-0005); never retries
- Registry: `agents.d` TOML persistence with atomic writes and reload-as-diff; mutation-serialized (race regression tested)
- Control plane: Unix control socket (§18 line-JSON) + `agentdctl` (init/register/update/unregister/list/reload/status); register-while-running dispatches immediately
- `agentd run` assembly: config loading, SIGHUP reload, graceful shutdown draining in-flight handlers
- Docs: agent guide (Agent-first), envelope JSON Schema v1, ops guide
- Tests: 102 unit/integration + 22-case E2E matrix (§21.2) against a real nats-server, run in CI
- Release: GitHub Release artifacts (x86_64/aarch64 × musl/gnu) and crates.io (`cargo install agent-daemon`)

### Miscellaneous

- Bootstrap repository scaffold: workflow (AGENTS.md), CI (lint / test / coverage / deny), release pipeline (cargo-zigbuild matrix), English whitepaper v0.1 with amendments, ADRs 0001–0003, and a compiling `agentd` / `agentdctl` skeleton with agent-id, envelope, and config foundations.
